# Limbuslikelrc

仿 **Limbus Company** 风格的网易云音乐桌面歌词悬浮窗。

自动识别当前播放歌曲 → 获取歌词 → 以逐字出现、抖动、描边、随机倾斜的方式显示。

## 功能

- 自动识别网易云当前歌曲（窗口标题）
- 自动从网易云获取 LRC 歌词
- 逐字出现 + 抖动 + 金色描边 + 随机倾斜
- 跟随播放 / 暂停（SMTC）
- 延迟补偿 + 手动偏移

## 系统要求

- **仅支持 Windows**
- 已安装并运行 [网易云音乐](https://music.163.com/)
- Python 3.9+

## 安装

```bash
pip install -r requirements.txt
